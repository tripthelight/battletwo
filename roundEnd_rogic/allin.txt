1) INDIANPOCKER_RULES.ALLIN 에서
사용 DATA:
"coinsPlayer", "coinsPlayerBet", "coinsPlayerExtBet", "coinsEnemy", "coinsEnemyBet", "coinsEnemyExtBet"

+-----+-----+-----+-----+-----+-----+-----+-----+-----+-----+-----+-----+-----+
콜카운트             : "coinsEnemyBet" - ("coinsPlayerBet" - "coinsPlayerExtBet")
작은 비교 숫자 1   : "coinsEnemy"
작은 비교 숫자 2   : ("coinsPlayer" + "coinsPlayerExtBet") - 콜카운트
+-----+-----+-----+-----+-----+-----+-----+-----+-----+-----+-----+-----+-----+

- 상대가 받는 올인 개수 :
비교 후 작은 숫자 + 콜카운트

- 배팅존에서 빼야하는 내 코인 개수 :
("coinsPlayerExtBet" - 상대가 받는 올인 개수) 가 
0 보다 크면 : ("coinsPlayerExtBet" - 상대가 받는 올인 개수)
0 보다 작으면 : 0

- 내가 올인 할 수 있는 개수 :
상대가 받는 올인 개수 - ("coinsPlayerExtBet" - 배팅존에서 빼야하는 내 코인 개수)

2) PlayerBlockMoveBattingZone 에서
- 배팅존에서 빼야하는 내 코인 개수가 0이면
  -  받은 data 그대로 resolve
- 내가 올인 할 수 있는 개수가 0이면
  - "coinsPlayerExtBet" 와 배팅존에서 빼야하는 내 코인 개수를 담아 resolve

사용 DATA:
"betCoin" -
  "betState", "host", "index", "translateX", "translateY", "offsetLeft", "offsetTop"

"betCoinPos" -
  "host", "translateX", "translateY"
  "host : pleyer"

- "betCoin", "betCoinPos" 에 내가 올일 할 수 있는 개수 만큼 추가

- "coinsPlayerBet" 의 값을 
  - "coinsPlayerBet" + 내가 올일 할 수 있는 개수 - 배팅존에서 빼야하는 내 코인 개수
- "coinsPlayerExtBett" 의 값을 
  - 상대가 받는 올인 개수 로 변경
