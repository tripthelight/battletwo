# 프로젝트 설명 :
현재 battletwo 프로젝트는 webRTC 기술을 이용한 2인용 웹게임들의 모음이다.
현재 `TAP! TAP!`과 `INDIAN POKER` 두 종류의 게임만 완성되어 있고, `BLACK AND WHITE 1`,과 `FIND THE SAME PICTURE` 는 작업 예정이다. `INDIAN POKER`를 먼저 완벽하게 만들고, 같은 환경에서 나머지 게임들을 붙여나갈 예정이다.

## 문제 상활 설명 :
`INDIAN POKER`를 만들고 보완해야될 부분을 알려줄테니 수정 보완해라.
1. 게임 플레이는 다 만들었는데, 브라우저에서 새로고침 할 경우, 버그가 존재한다.
- 두 peer가 webRTC로 매칭 완료됨 > 배팅의 선, 후를 결정(gameState: choiceCard) > 기본 배팅 후, `gameState` `playing` 진입 > call, allin, fold 시 결과를 알려주는 animation 진행됨 > 이 때, 브라우저 새로고침 시, 새로고침 한 peer는 빈화면 노출됨 > 상대 peer는 이 후 단계 진행되지만, 새로고침 한 peer는 빈 화면에서 멈춰있는 상태

※ 요구사항 :
1. 새로고침을 한 peer는 그 즉시, 로딩화면이 노출되어야 한다.
2. 상대 peer 가 이번 라운드의 결과를 알려주는 animation이 끝나고, 다음 단계로 진입하면, 새로고침 한 peer도 같은 단계로 진입되어야 한다.
3. 결과를 알려주는 animation 단계에서 두 peer가 모두 새로고침했다면, 두 peer 모두 즉시 다음 단계로 매칭되어야 한다.
4. ***중요: 두 peer의 단계가 같다는 것이 증명되어야만 서로 다음 단계로 진입해야 한다.

현재의 코드 전체 상태를 완벽히 이해하고, 오류없이, 에러없이 나의 지시시항을 수행해라.

현재 battletwo 프로젝트는 webRTC 기술을 이용한 2인용 웹게임들의 모음이다.
현재 `TAP! TAP!`, `INDIAN POKER`, `FIND THE SAME PICTURE` 는 작업 예정이다.
`BLACK AND WHITE 1`를 먼저 완벽하게 만들고, 같은 환경에서 나머지 게임들을 붙여나갈 예정이다.

## 문제 상활 설명 :
`BLACK AND WHITE 1`에서 보완해야될 부분을 알려줄테니 수정 보완해라.
1. 게임 플레이는 다 만들었는데, 게임 진행 중 알 수 없는 에러가 발생한다.
  1) 두 peer가 webRTC로 매칭 완료됨
  2) 두 peer는 서로의 cube를 섞음(`gameState: waitEnemyShuffle`)
  4) 두 peer 모두 `START` 버튼을 클릭
  5) 선/후 플레이어 지정(`gameState: setOrder`)
  6) `gameState` `playing` 진입 후 Round를 진행
  7) 이 전 Round의 결과가 동(同)점 일 경우 :
    - 현재 턴의 peer가 `.black-square` 영역으로 cube를 옮겨도, 상대 peer에게 턴이 안넘어간다.

※ 요구사항 :
1. 어느 시점, 어떤 상황, 어떤 화면에서도 두 peer의 턴은 정확해야 한다.
2. ***중요: `BLACK AND WHITE 1`의 모든 data는 플레이어가 알아챌 수 없도록 암호화 되어있다. 암호화 로직이 어떻게 구현되어 있는지 정확히 분석하고 이해한 후, 수정해라.
3. 전체 코드를 정확히 분석해서, 게임 진행에 문제가 되는 로직이 있다면 네가 알아서 수정, 보완, 리펙토링 해라.

현재의 코드 전체 상태를 완벽히 이해하고, 오류없이, 에러없이 나의 지시시항을 수행해라.

# 프로젝트 설명 :
현재 battletwo 프로젝트는 webRTC 기술을 이용한 2인용 웹게임들의 모음이다.
현재 `TAP! TAP!`과 `INDIAN POKER`, `BLACK AND WHITE 1`은 작업 예정이다. `FIND THE SAME PICTURE`를 먼저 완벽하게 만들고, 같은 환경에서 나머지 게임들을 붙여나갈 예정이다.

## 문제 상활 설명 :
`FIND THE SAME PICTURE`에서 보완해야될 부분을 알려줄테니 수정 보완해라.
1. 게임 플레이는 다 만들었는데, 게임 진행 중 알 수 없는 에러가 발생한다.
  1) 두 peer가 webRTC로 매칭 완료됨
  2) 선/후 플레이어를 결정(`gameState: stateChoiceFirstPlayer`)
  3) `gameState` `playing` 진입
  4) 서로의 알파벳을 뒤집으면서 게임 진행
  5) 상대 peer가 틀리거나 맞추었을 경우, 자신의 말인 `div.player-icon` 사각형 tag element가 좌/우로 한 칸씩 이동해야 하는데, 이상하게 막 몇 칸씩 이동한다. 그리고, 그 후에 알 수 없는 에러가 막 발생한다.

※ 요구사항 :
1. 자신의 말인 `div.player-icon` tag element는 뒤집은 알파벳이 맞으면 왼쪽, 틀리면 오른쪽으로 한 칸 씩 이동해야 한다.
2. ***중요: `FIND THE SAME PICTURE`의 모든 data는 플레이어가 알아챌 수 없도록 암호화 되어있다. 암호화 로직이 어떻게 구현되어 있는지 정확히 분석하고 이해한 후, 수정해라.
3. 전체 코드를 정확히 분석해서, 게임 진행에 문제가 되는 로직이 있다면 네가 알아서 수정, 보완, 리펙토링 해라.

현재의 코드 전체 상태를 완벽히 이해하고, 오류없이, 에러없이 나의 지시시항을 수행해라.
